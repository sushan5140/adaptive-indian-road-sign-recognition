**Subject:** Academic access and permitted-use clarification for IRSDBv1.0

Dear IRSDBv1.0 maintainers,

I am working on a non-commercial academic internship project titled **“Adaptive Indian Road Sign Recognition Using Open-Set and Few-Shot Learning.”** The project studies whether a frozen road-sign classifier can identify unfamiliar signs as unknown and subsequently recognize new sign classes from a small, separately maintained reference set.

The public IRSDBv1.0 write-up states that the database contains 1,692 Indian traffic-sign images across 49 classes, that training images are organized into tracks representing individual physical signs, and that access is available on request for research use. I would be grateful if you could provide:

1. Access to IRSDBv1.0 and any accompanying documentation.
2. The complete 49-class manifest, including the mapping between folder IDs and semantic class names.
3. Per-class image counts and per-class physical-sign/track counts.
4. Confirmation whether the dataset contains the following exact classes:
   - stop
   - no left turn
   - maximum speed limit 50 km/h
   - no parking

Please also confirm whether your permission covers:

- non-commercial academic model training and evaluation;
- open-set and few-shot experiments;
- creation of derived traffic-sign crops;
- storage of the original files and derived crops in a local or access-controlled private Git repository;
- inclusion of a small number of attributed example images or contact sheets in internship/project reports; and
- publication of aggregate metrics, tables, and methodological findings.

Finally, please state any restrictions on redistribution, sharing with collaborators, retention, publication, or release of derived files, as well as the required citation and attribution wording. We will not publicly redistribute the dataset unless you explicitly permit it.

Thank you for considering this request. I can provide a short protocol description or institutional details if needed.
